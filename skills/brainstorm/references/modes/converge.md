# Mode: Converge

Narrow toward a decision. Usually a *short tail* after reframe/pressure-test, not a long phase — the user
often picks with one word once the options are clear.

## The mechanic

1. **Trigger the cut deliberately.** When the option count crosses ~5–7, or the user starts re-weighing
   already-seen options, that's the signal to stop diverging and force a choice. Satisfice: take the first
   option that clears the bar rather than seeking the global optimum.
2. **When a holistic ranking wobbles, decompose into pairwise comparisons.** There can be any number of options
   on the table — don't force everything into twos. But when ranking many options at once feels arbitrary or
   unstable, compare them two at a time against the user's stated criteria and compose the result: pairwise
   calls are far more consistent than one global verdict, and they surface exactly where a cycle/tension lives
   ("A beats B on cost, B beats A on risk — the real fork is which you weight"). It's a reliability tool, not a
   cap on how many options may be considered at once.
3. **Recommend one path with reasoning** (not a neutral matrix), then hold it loosely.
4. **Attach the evidence** each judgment rests on, so the user can override in seconds.

## Watch-out

The user should be able to restate and defend the chosen position to a third party themselves. If they can
only say "the AI recommended it," convergence failed — you talked them into it (sycophancy's mirror image).
